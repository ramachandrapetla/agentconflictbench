# Baseline Results Report

This report summarizes the lightweight feature baseline generated by
`scripts/baseline_features.py`. The features are descriptive only: the current
dataset contains reproduced positive conflict instances and does not yet include
negative controls.

## Current Snapshot

After the JS/TS growth round, AgentConflictBench contains 25 reproduced
instances across seven upstream repositories.

## Feature Table

The generated CSV lives at:

```text
analysis/baseline_features.csv
```

It records:

- repository and language;
- conflict type and difficulty;
- touched-file overlap between Patch A and Patch B;
- patch size in added/deleted lines;
- changed-token Jaccard similarity;
- task-description token Jaccard similarity.

## Interpretation

These features are intentionally simple. They support baseline detectors such
as:

- always-conflict;
- same-file overlap;
- shared changed-token overlap;
- task-description similarity;
- patch-size heuristics.

The main limitation is that there are not yet negative controls, so these
features should be reported as dataset characterization rather than classifier
performance. Once controls are introduced, the same CSV can support precision,
recall, ROC-AUC, and calibration experiments.

or evaluate simple oracle-free baselines against both positive and control
