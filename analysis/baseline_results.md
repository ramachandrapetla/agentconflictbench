# Baseline Results Report

This report summarizes the lightweight feature baseline generated by
`scripts/baseline_features.py`. The features are descriptive and now include
both reproduced positive conflict instances and initial clean-composition
controls.

## Current Snapshot

After the initial control round, AgentConflictBench contains 28 reproduced
instances across seven upstream repositories: 25 positive conflict instances and
3 clean-composition controls.

## Feature Table

The generated CSV lives at:

```text
analysis/baseline_features.csv
```

It records:

- repository and language;
- conflict type and difficulty;
- touched-file overlap between Patch A and Patch B;
- patch size in added/deleted lines;
- changed-token Jaccard similarity;
- task-description token Jaccard similarity.

## Interpretation

These features are intentionally simple. They support baseline detectors such
as:

- always-conflict;
- same-file overlap;
- shared changed-token overlap;
- task-description similarity;
- patch-size heuristics.

The current controls make first-pass precision, recall, ROC-AUC, and
calibration experiments possible. The main limitation is that control coverage
is still small, so classifier results should be framed as preliminary until the
control set is expanded.

## Next Baseline Step

Expand matched controls to at least 10 examples, then evaluate simple
oracle-free baselines against both positive and control instances.
