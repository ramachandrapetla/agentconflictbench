# Baseline Results Report

This report summarizes the lightweight feature and classifier baselines
generated by `scripts/baseline_features.py` and
`scripts/baseline_classifier.py`. The features are descriptive and now include
both reproduced positive conflict instances and initial clean-composition
controls.

## Current Snapshot

After the initial control round, AgentConflictBench contains 28 reproduced
instances across seven upstream repositories: 25 positive conflict instances and
3 clean-composition controls.

## Feature Table

The generated CSV lives at:

```text
analysis/baseline_features.csv
```

The classifier-style baseline report lives at:

```text
analysis/baseline_classifier_results.md
```

It records:

- repository and language;
- conflict type and difficulty;
- touched-file overlap between Patch A and Patch B;
- patch size in added/deleted lines;
- changed-token Jaccard similarity;
- task-description token Jaccard similarity.

## Interpretation

These features are intentionally simple. They support baseline detectors such
as:

- always-conflict;
- same-file overlap;
- shared changed-token overlap;
- task-description similarity;
- patch-size heuristics.

The current controls make first-pass precision, recall, ROC-AUC, and
calibration experiments possible. In the first generated classifier report,
`same_file` is the strongest simple heuristic by balanced accuracy, while
`always_conflict` remains a useful sanity check because it has zero specificity
on controls. The main limitation is that control coverage is still small, so
classifier results should be framed as preliminary until the control set is
expanded.

## Next Baseline Step

Expand matched controls to at least 10 examples, then rerun and compare the
oracle-free baselines against both positive and control instances.
